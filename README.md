# Web Scraping Internship Project

This project scrapes book data from books.toscrape.com using Python & BeautifulSoup.

## Features
- Pagination support
- Extract title, price, rating
- Export to Excel

## Tools Used
- Python
- BeautifulSoup
- Requests
- Pandas

## Output
Data saved into `books.xlsx`.
